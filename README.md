## Visualización local
Abre `index.html` en un navegador. No requiere instalación ni compilación.

El diseño oscuro y morado incluye navegación móvil, tecnologías agrupadas con logos SVG y enlaces directos de contacto. Las animaciones respetan la preferencia de movimiento reducido y el contenido permanece disponible sin JavaScript.

Para comprobar cambios, revisa la página en escritorio y celular, abre y cierra el menú (también con Escape), prueba los enlaces de navegación y contacto, y verifica la vista previa de ELIEZER. Los logos de tecnologías requieren conexión a Internet.

## Actividad de GitHub
El calendario usa datos reales de la API GraphQL de GitHub. Para regenerarlo localmente, con Node.js y GitHub CLI autenticado, ejecuta `node scripts/github-activity.cjs`.

El workflow `Update GitHub activity` lo actualiza diariamente a las 08:20 UTC y permite ejecución manual desde Actions. Necesita permiso de escritura de contenido para guardar `assets/github-activity.svg`; los errores de API hacen fallar el workflow sin reemplazar el último gráfico válido. El token se proporciona como `GH_TOKEN`, nunca en el navegador.

En GitHub Pages la imagen se lee desde la rama `main` mediante `raw.githubusercontent.com`, para recibir las actualizaciones programadas sin depender de un nuevo despliegue de Pages. Localmente y sin JavaScript se utiliza la copia incluida en el sitio. El calendario muestra la fecha de actualización y refleja únicamente los datos que GitHub expone al token del workflow.
